# MonteeMageMogol

MonteeMageMogol is a lightweight addon for The Elder Scrolls Online that filters LoreBooks map pins to display only Mages Guild (Shalidor’s Library) books.

The addon hides:

* Eidetic Memory books
* Bookshelf pins
* Other unnecessary LoreBooks categories

This keeps the map cleaner and focused for Mages Guild progression and lorebook farming.

## Features

* Mage Guild only mode
* LoreBooks integration
* Lightweight and future-friendly design
* Settings menu support
* LibMapPins support

## Dependencies

Required addons/libraries:

* LoreBooks
* LibMapPins-1.0
* LibAddonMenu-2.0

## Installation

Extract the addon folder into:

Documents/Elder Scrolls Online/live/AddOns/
